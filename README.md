## Stage 1: Data Cleaning Highlights (`01_clean_data.py`)
1. **Target Cleaning**: Converted mixed formats (`"Yes"`, `"1.0"`, `"Y"`, etc.) into `1` / `0`. Dropped unresolvable target rows.
2. **Numeric Standardisation**: Stripped symbols (`Rs.`, `,`), handled word numbers (`thirty`), and converted columns using `pd.to_numeric(errors="coerce")`.
3. **Categorical Standardisation**: Cleaned, lowercased, and mapped messy labels into standard categories for `gender`, `employment_type`, `city_tier`, and `loan_purpose`.
4. **Date Parsing**: Extracted `application_year` and `application_month`, while dropping invalid dates (<2018 or future).
5. **Logical Bounds & Outlier Handling**: Set out-of-bound values (`age` < 18, impossible `credit_score`, negative debt/income) to `NaN`. Winsorised money-related columns at the 1st and 99th percentiles using training bounds stored in `winsor_bounds.json`.
6. **Missingness Indicator**: Added `income_missing` column before leaving remaining missing values to scikit-learn imputers inside the pipeline.

---

## Stage 2: Modelling & Results (`02_train_model.py`)
- **Pipeline Architecture**: `ColumnTransformer` with Median Imputer + `StandardScaler` for numerical features and Most Frequent Imputer + `OneHotEncoder` for categorical features.
- **Cross-Validation**: 5-Fold Stratified Cross-Validation on training split (80/20 split, `random_state=42`).
- **Models Compared**: Logistic Regression (`class_weight="balanced"`) vs Random Forest (`class_weight="balanced"`).
- **Evaluation**: Evaluated using **ROC-AUC** and **PR-AUC** due to class imbalance (~11% positive target).
- **Threshold Tuning**: Tuned decision threshold to **0.35** to achieve ~80% Recall on defaulters.

### Key Metrics Summary (Held-out Test Set)
- **ROC-AUC**: `0.7425`
- **PR-AUC**: `0.4222`
- **Recall (Defaulters @ 0.35 threshold)**: `80.18%`
- **Top Risk Factors**: `employment_type_Unemployed`, `dti_ratio`, `employment_type_Retired`, `credit_score`, `previous_default`.

## How to Run

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run Data Cleaning (Stage 1)**:
   ```bash
   python 01_clean_data.py
   ```

3. **Run Model Training & Evaluation (Stage 2)**:
   ```bash
   python 02_train_model.py
   ```

4. **Run Test Suite (Steps 1 - 4)**:
   ```bash
   python 03_test_sanity.py
   python 04_test_new_data.py
   python 05_test_robustness.py
   python 06_threshold_analysis.py
   ```

5. **Launch Interactive Streamlit Web Demo (Step 5)**:
   ```bash
   streamlit run app.py
   ```
